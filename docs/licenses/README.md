# Supplemental licence sources

These package archives omit root licence files. Texts were retrieved from their recorded upstream source revisions on 2026-11-09, or from the licence steward as explicitly directed by source headers. The generator pins supplements to exact package versions so upgrades require review.

- alloc-stdlib 0.3.0: [Dropbox BSD licence](https://github.com/dropbox/rust-alloc-no-stdlib/blob/0a81fd6928ea3b33c8cd484aa4575d50ffb98012/LICENSE).
- tauri-plugin 2.7.2: [Tauri MIT licence](https://github.com/tauri-apps/tauri/blob/59b63ab500da9859f12d8888c3298bc29bba0b92/LICENSE-MIT), using the package's MIT option.
- webview2-com and webview2-com-sys 0.39.1: [Bill Avery MIT licence](https://github.com/wravery/webview2-rs/blob/edc2caf886175ccaebe86078c9cfe1ae2a187328/LICENSE).
- webview2-com-macros 0.8.1: [same licence at its source revision](https://github.com/wravery/webview2-rs/blob/dffa41a8a46d3f5565eefbff2de57d38d399f158/LICENSE).
- selectors 0.38.0: source headers declare MPL 2.0 and direct readers to Mozilla. [Official licence text](https://www.mozilla.org/media/MPL/2.0/index.txt); [unmodified source revision](https://github.com/servo/stylo/tree/572ecba2d1600e7c3d490586692a209faf703baa/selectors). The generated notice includes a corresponding-source download link.

Fontsource Inter, Space Grotesk and JetBrains Mono licence files and Lucide's ISC/MIT notices are collected from installed packages. The current app uses local fonts, Lucide icons, CSS shapes and text; it does not bundle reference mockup screenshots or game artwork. FFmpeg is user-supplied and not redistributed. Windows Authenticode signing and clean-machine release validation remain separate release prerequisites.
